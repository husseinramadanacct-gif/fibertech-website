# موقع FiberTech - شركة الفايبر جلاس

موقع إلكتروني كامل وجاهز لشركة **FiberTech** المتخصصة في منتجات الفايبر جلاس.

## الملفات

- `index.html` → الصفحة الرئيسية
- `style.css` → التنسيقات
- `script.js` → التفاعلات

## طريقة الرفع المجانية (اختر واحدة)

### 1. Netlify (الأسهل)
1. ادخل على [netlify.com](https://www.netlify.com)
2. اسحب مجلد `fibertech-website` بالكامل على الصفحة
3. الموقع ينشر فورًا برابط مجاني

### 2. Vercel
1. ادخل على [vercel.com](https://vercel.com)
2. ارفع المجلد أو اربطه بـ GitHub

### 3. GitHub Pages
1. ارفع الملفات على مستودع GitHub
2. من Settings → Pages → اختر الفرع
3. الموقع يكون جاهز على `username.github.io/repo-name`

## تخصيص الموقع

- غيّر رقم الهاتف والبريد والعنوان في قسم "تواصل معنا"
- عدّل الإحصائيات في قسم "من نحن" لو حابب
- لو عايز تربط فورم التواصل بإيميل حقيقي:
  - استخدم [Formspree](https://formspree.io) (مجاني)
  - أو [EmailJS](https://www.emailjs.com)
